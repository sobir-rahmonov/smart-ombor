# Omborxona Boshqaruv Tizimi (Inventory Management System)

Ushbu loyiha **Django** freymvorki yordamida to'liq (Full-stack) ishlab chiqilgan bo'lib, omborxona kirim va chiqimlarini hisobga olish hamda foydalanuvchilar faoliyatini boshqarishga mo'ljallangan.

## 🚀 Asosiy imkoniyatlari (Features)

* **Admin boshqaruvi:** Admin tizimga yangi foydalanuvchilarni qo'shadi hamda ularga tizimga kirish uchun login va parol biriktiradi.
* **Xavfsiz autentifikatsiya:** Foydalanuvchilar admin tomonidan berilgan login va parol orqali tizimga kirishadi.
* **Shaxsiy kabinet va ma'lumotlar ajratilishi:** Har bir foydalanuvchi faqat o'ziga tegishli bo'lgan kirim va chiqim ma'lumotlarini ko'ra oladi va boshqara oladi.
* **Kirim va chiqim hisoboti:** Omborga kirgan va chiqqan mahsulotlarning aniq va tartibli hisobi yuritiladi.

## 🛠 Texnologiyalar (Tech Stack)

* **Backend:** Python, Django
* **Frontend:** Django Templates, HTML5, CSS3, JavaScript
* **Database:** SQLite / PostgreSQL
